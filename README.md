# GoPoint

Навигатор по общественному транспорту Новосибирска с режимом низкопольного транспорта.
Сайт для телефона (PWA): видно транспорт на линии сейчас, маршрут от точки А до точки Б.

[План разработки и текущий шаг](docs/ROADMAP.md) · [правила работы](AGENTS.md) · [устройство кода](docs/ARCHITECTURE.md).

OpenTripPlanner рассчитывает путь по улицам и расписанию. Для транспортного поиска нужен проверенный комплект графа. Низкопольный режим включён по умолчанию и требует свежего подтверждения каждой посадки. [План перехода](docs/ROUTING.md)

## Запуск демо на Mac

Коротко и с ответами «что делать, если не запустилось»: `docs/DEMO_RUN.md`.
Сценарий показа и отчёт о проверке v0.4 от 05.11: `docs/DEMO_CHECKLIST.md` (замеры того дня, не текущие требования).

1. Откройте **Docker Desktop** (значок кита в «Программах») и дождитесь, пока он запустится.
2. Откройте «Терминал», перейдите в папку проекта и выполните:

   ```bash
   bash scripts/run-demo.sh
   ```

3. Скрипт напечатает два адреса: для этого компьютера (`http://localhost:8080`) и для телефона
   (`http://192.168.…:8080`). Телефон должен быть в той же сети Wi-Fi, что и Mac.

Остановить: `bash scripts/stop-demo.sh`.

### Транспортный комплект OTP

Обычный запуск использует уличный граф. Для транспортного поиска экспортируйте каталог и ID одного комплекта и запустите демо из корня проекта. Пример для уже подготовленного локального комплекта:

```bash
export GOPOINT_RT_DIR="$PWD/data/otp/stop-review-f-docker-2026-11-25"
export GOPOINT_RT_VERSION=4c604bde5ccee8453d12c4b02b4e03f3dac79c8cc5c915652e969b6246834d8e
bash scripts/run-demo.sh
```

Тестовый комплект содержит 128 групп на 64 маршрутах и действует с 24.11 по 06.12.2026. Файлы комплекта хранятся локально. Для смены версии запустите демо с каталогом и ID подготовленного комплекта. OTP и API получат одну версию. Сохраните предыдущий комплект для отката на время проверки. После окончания календаря поиск сообщает о недоступности транспорта и сохраняет короткий пеший вариант, когда он есть. [Подготовка и установка графа](docs/ROUTING.md#72-повторное-использование-графа-и-установка-версии)

### Поиск адресов (один раз)
Подсказки адресов работают на своей базе только по Новосибирску. Её нужно собрать один раз
(около 5 минут, скачивается файл 1,5 ГБ):

```bash
bash scripts/build-photon-db.sh
```

Раз в несколько месяцев можно обновить адреса: `bash scripts/build-photon-db.sh --fresh`.
Файл `data/photon/photon-dump-russia.jsonl.zst` после сборки можно удалить, он нужен только для обновления.

### Пешие участки (один раз)
Путь пешком считает OpenTripPlanner по улицам Новосибирска. Граф улиц нужно собрать один раз
(около 5 минут, скачивается файл 590 МБ):

```bash
bash scripts/build-otp-graph.sh
```

Обновить улицы раз в несколько месяцев: `bash scripts/build-otp-graph.sh --fresh`.
Прежний замер уличного OTP — около 600 МБ, параметры сборки допускают heap до 3 ГБ; это не замер будущего транспортного графа. Сначала доводим полный стек до стабильной работы в Docker на Mac, без ограничения 4 ГБ; граф и базу Photon можно готовить на том же Mac отдельными командами. Сервер выбираем после замеров готового приложения по [плану шага 04](docs/ROUTING.md).
Файл `data/osm/siberian-fed-district.osm.pbf` после сборки можно удалить, он нужен только для обновления.

### Открыть на телефоне
1. Телефон подключите к той же сети Wi-Fi, что и Mac (не к гостевой).
2. В браузере телефона откройте адрес «На телефоне» из вывода скрипта, например `http://192.168.3.26:8080`.
   Адрес может меняться после перезагрузки роутера: смотрите его каждый раз в выводе скрипта.
3. Если macOS спросит, разрешить ли входящие подключения для Docker, нажмите «Разрешить».

По такому адресу (http) не работает кнопка «Моё местоположение»: браузеры дают местоположение
только защищённым адресам (https). Для неё нужен временный туннель (ниже).

### Временный HTTPS-адрес (туннель)
Нужен, чтобы на телефоне работала кнопка «Моё местоположение» или чтобы открыть сайт не из
домашней сети (через мобильный интернет). Сначала запустите демо, потом:

```bash
bash scripts/run-tunnel.sh
```

Скрипт напечатает адрес вида `https://….lhr.life`: откройте его на телефоне. Адрес случайный и
меняется при каждом запуске. **Пока туннель работает, сайт доступен из интернета любому, кто знает
адрес**, поэтому после проверки выключайте его:

```bash
bash scripts/stop-tunnel.sh
```

Если сайт по адресу туннеля перестал открываться, запустите `run-tunnel.sh` ещё раз: бесплатный
туннель иногда обрывается.

### Если не запустилось
- **«Docker не запущен»**: откройте Docker Desktop, подождите минуту, запустите команду снова.
- **Телефон не открывает адрес**: проверьте, что телефон и Mac в одной сети Wi-Fi (не гостевой);
  при первом запуске macOS может спросить, разрешить ли входящие подключения: ответьте «Разрешить».
- **Что-то другое**: выполните `docker compose logs --tail 50` и пришлите результат.

### Не засыпать
Пока идёт показ, Mac не должен засыпать, иначе сайт на телефоне перестанет открываться.
Самый простой способ: в отдельном окне «Терминала» выполните

```bash
caffeinate -dims
```

и не закрывайте это окно до конца показа (закрыть: Control+C). Ноутбук при этом должен быть
подключён к зарядке и с открытой крышкой.

### Память для Docker
Для текущего демо с уличным OpenTripPlanner и Photon исходная рекомендация — выделить Docker Desktop не меньше 4 ГБ памяти. Это рекомендация для запуска, **не верхний лимит проекта** и не доказанная потребность будущего транспортного графа. По мере добавления расписаний и сборки при необходимости увеличить память/CPU, оставив запас macOS и другим приложениям. Фактические ресурсы полного стека измеряются отдельно.
Посмотреть или изменить: Docker Desktop → Settings → Resources → Memory.

```bash
bash scripts/check-all.sh
```
