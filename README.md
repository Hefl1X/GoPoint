# GoPoint

Навигатор по общественному транспорту Новосибирска с режимом низкопольного транспорта.
Сайт для телефона (PWA): видно транспорт на линии сейчас, маршрут от точки А до точки Б.

Правила проекта: `CLAUDE.md`. Устройство: `docs/ARCHITECTURE.md`. Где остановились: `docs/HANDOFF.md`.

## Запуск демо на Mac

1. Откройте **Docker Desktop** (значок кита в «Программах») и дождитесь, пока он запустится.
2. Откройте «Терминал», перейдите в папку проекта и выполните:

   ```bash
   bash scripts/run-demo.sh
   ```

3. Скрипт напечатает два адреса: для этого компьютера (`http://localhost:8080`) и для телефона
   (`http://192.168.…:8080`). Телефон должен быть в той же сети Wi-Fi, что и Mac.

Остановить: `bash scripts/stop-demo.sh`.

### Открыть на телефоне
1. Телефон подключите к той же сети Wi-Fi, что и Mac (не к гостевой).
2. В браузере телефона откройте адрес «На телефоне» из вывода скрипта, например `http://192.168.3.26:8080`.
   Адрес может меняться после перезагрузки роутера: смотрите его каждый раз в выводе скрипта.
3. Если macOS спросит, разрешить ли входящие подключения для Docker, нажмите «Разрешить».

**Кнопка «Моё местоположение» на телефоне по такому адресу не сработает.** Браузеры дают
местоположение только сайтам с защищённым адресом (https), а в домашней сети адрес обычный (http).
Сайт в этом случае честно пишет, почему местоположения нет, и продолжает работать. На самом Mac
(`http://localhost:8080`) кнопка работает. Как включить её и на телефоне, решает владелец
(варианты в `docs/HANDOFF.md`, раздел «Вопросы к владельцу»).

### Если не запустилось
- **«Docker не запущен»**: откройте Docker Desktop, подождите минуту, запустите команду снова.
- **Телефон не открывает адрес**: проверьте, что телефон и Mac в одной сети Wi-Fi (не гостевой);
  при первом запуске macOS может спросить, разрешить ли входящие подключения: ответьте «Разрешить».
- **Что-то другое**: выполните `docker compose logs --tail 50` и пришлите результат.

### Не засыпать
Пока идёт показ, Mac не должен засыпать, иначе сайт на телефоне перестанет открываться.
Самый простой способ: в отдельном окне «Терминала» выполните

```bash
caffeinate -dims
```

и не закрывайте это окно до конца показа (закрыть: Control+C). Ноутбук при этом должен быть
подключён к зарядке и с открытой крышкой.

### Память для Docker
Сейчас Docker Desktop отдаёт контейнерам около 7,7 ГБ памяти. Для будущего OpenTripPlanner
(пешие маршруты) нужно не меньше 4 ГБ, так что менять ничего не нужно. Посмотреть или изменить:
Docker Desktop → Settings → Resources → Memory.

## Проверки

Все проверки одной командой (нужны `uv` и Node.js; проверить компьютер: `bash scripts/check-mac.sh`):

```bash
bash scripts/check-all.sh
```
