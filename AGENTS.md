# Работа над GoPoint

Актуальные задачи, проверки и точка продолжения находятся в [ROADMAP.md](docs/ROADMAP.md). В начале сессии сверь ветку, рабочие изменения и последний коммит с разделом «Продолжить отсюда». Если предыдущая задача прервалась, проверь открытый PR и её удалённую ветку. Историю первой версии смотри в git по тегу `v0.4-stops-panorama-motion`.

- Каждый шаг веди в указанной в плане ветке. После проверяемой части обнови точку продолжения, сделай коммит и push. Правила завершения и восстановления записаны в плане.
- Объясняй изменения владельцу по-русски. Для изменений поведения проверь сценарий в браузере на ширине 360 px и на запущенном Docker-демо. Различай наблюдения на живых данных и результаты на фиксированных примерах.
- Сохраняй доступность интерфейса, строгие типы, границы адаптеров и действующие проверки CI. Для дефекта добавь проверку, которая воспроизводит его.
- Координаты пользователей и поисковые запросы не сохраняй в журналах. Секреты храни в локальном .env. Согласуй новые платные сервисы, расширение сбора внешних данных и публичный запуск с владельцем. Отправка рабочих веток в GitHub предусмотрена планом.
- Команды запуска и проверок находятся в README. Справочники архитектуры, лицензий и источников открывай по теме текущего шага.
