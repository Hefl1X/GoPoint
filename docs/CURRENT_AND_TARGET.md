# GoPoint — текущее и целевое состояние

Состояние миграции маршрутизации на 27 ноября 2026 года. Этапы и критерии описаны в [ROUTING.md](ROUTING.md), точка продолжения — в [ROADMAP.md](ROADMAP.md).

| Возможность | Сейчас | Оставшаяся работа |
|---|---|---|
| Расписание | Сборщик читает полные таблицы ЦУГАЭТ, сохраняет времена каждого рейса и формирует GTFS. Офлайн-выгрузка включает 144 из 302 групп. | Подтвердить площадки остальных 158 групп. Продлить календарь и проверить права на распространение перед публичным запуском. [Аудит источника](../data/tsugaet/SCHEDULE.md) |
| Поиск поездки | Один OTP рассчитывает ходьбу, ожидание, транспорт и пересадки. Общий режим использует расписание при отсутствии GPS. `JourneyService` проверяет всю выбранную цепочку. | После сверки площадок повторить проверку на расширенном графе. |
| Низкопольный режим | Включён по умолчанию. Для каждой посадки требуется свежее подтверждение рейса машиной с `ramp=1`. Оба фида используют один GPS-прогноз. | Оценить точность сопоставления по независимой разметке рейсов и доступность низкопольных вариантов в разное время. |
| Смена графа | Уличная часть используется повторно. OTP и Python загружают одну версию комплекта. Предыдущий комплект пригоден для отката. | Собрать оставшиеся группы одной партией, затем обновить граф и проверить оба фида. |
| Обновления | Внутренний GTFS-Realtime обновляется каждые 10 секунд. GPS опрашивается не чаще 30 секунд при активности. Разовые архивные сборы ограничены бюджетом. | Подключить регулярную проверку расписания после согласования объёма. Изменения GPS обрабатываются без пересборки графа. |
| Локальное демо | Caddy, FastAPI, OTP и Photon работают в Docker на Mac. Последний собранный граф включает 128 групп на 64 маршрутах. | Подбор сервера после замеров готового приложения. |
| Карта, адреса и live-функции | Карточки машин, остановки и прибытия работают отдельно от поиска поездки. Адреса обрабатывают Photon и локальные подсказки. | Плавность движения, панорамы и качество адресных подсказок ведутся отдельными шагами. |
