# GoPoint сегодня и после доработки

Состояние на 21 ноября 2026 года. Главная задача — построить путь между двумя точками по расписанию и уточнить ожидание по GPS. Для поездок используем транспорт ЦУГАЭТ.

| Что | Сейчас | К чему прийти |
|---|---|---|
| Общее дневное расписание | GoPoint получает линии, остановки и положения машин. Полное расписание на день приложение пока не загружает. | Каждые **5 часов** проверять официальное расписание. Для каждого направления учитывать дни работы, порядок остановок, плановые отправления или опубликованные интервалы. |
| Низкопольное расписание | Низкий пол определяется по признаку `ramp` у видимой машины. Отдельного расписания низкопольных рейсов нет. | Каждые **30 секунд** брать тот же GPS-снимок, что и для карты. Сопоставлять машину с конкретным отправлением дневного расписания. Из отправлений с подтверждённым `ramp = 1` формировать **второе, низкопольное расписание**. |
| Построение пути | Транспортные участки и пересадки ищет `LiveTransit` по машинам на линии. OpenTripPlanner (OTP) строит пешие участки. Если автобус уже проехал остановку посадки, расчёт может пропустить следующий рейс. | OTP строит весь путь по выбранному расписанию и пешеходной сети OSM. Свежий прогноз влияет на выбор посадки и пересадки. Сравниваем полное время от А до Б с учётом ходьбы, ожидания и поездки. |
| Выбор режима | Оба режима есть. По умолчанию выбран «Весь транспорт». | По умолчанию — **«Низкопольный транспорт»**. Каждую посадку, включая пересадки, подбирать по низкопольному расписанию. При выборе **«Весь транспорт»** использовать общее дневное расписание. |
| Варианты поездки | На прямом направлении приложение иногда отвечает «Транспорта сейчас нет». | Если машина ушла в депо или пропал GPS, сохранять схему пути и длительность проезда. Для ожидания брать следующее подходящее отправление. Если ожидание неизвестно, указывать это отдельно. При наличии двух подходящих вариантов показывать оба, пешие участки включать в шаги поездки. |
| Карта и панорамы | Стандартная подложка OSM уже подключена. Машины движутся рывками, а панорама может открыться в стороне от остановки. | Сохранить подложку, плавно перемещать маркеры между GPS-отметками. По нажатию на панораму показывать нужную посадочную площадку. |
| Поиск точек А и Б | Точный адрес бывает трудно найти. По названию места в выдачу может попасть одноимённая трасса. | По запросу «Военная 5» находить здание с этим адресом, по «Кольцово» — населённый пункт. Давать выбрать улицу без номера или точку на карте и сохранять названия А и Б в маршруте. Поиск отложен до проверки ядра маршрутизации. |

**Контрольный пример — «Цветной проезд → Речной вокзал».** На автобусе № 8 предстоит проверить покрытие официального расписания, различить два соседних отправления по данным ЦУГАЭТ и показать прямую поездку после ухода предыдущей машины. Отдельная проверка для OTP — подобрать низкопольный транспорт на обеих посадках в поездке с пересадкой.
