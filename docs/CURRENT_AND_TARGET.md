# GoPoint сегодня и после доработки

Состояние на 21 ноября 2026 года. Главная задача — построить путь между двумя точками по расписанию и уточнить ожидание по GPS. Для поездок используем транспорт ЦУГАЭТ. Согласованная архитектура и решения владельца — [ROUTING.md](ROUTING.md).

| Что | Сейчас | К чему прийти |
|---|---|---|
| Общее дневное расписание | GoPoint получает линии, остановки и положения машин. Полное расписание на день приложение пока не загружает. | Официальное расписание `grasp.php` переводить в GTFS. Формат разобран по образцам ([SCHEDULE.md](../data/tsugaet/SCHEDULE.md)): все остановки, типы дня, отправления; номеров выходов и низкого пола нет; время хода постоянно весь день. Частота регулярного обновления ждёт решения владельца (предложено раз в сутки по таблицам конечных). |
| Низкопольное расписание | Низкий пол определяется по признаку `ramp` у видимой машины. Отдельного расписания низкопольных рейсов нет. | Каждые **30 секунд** брать тот же GPS-снимок, что и для карты. Сопоставлять машину с конкретным отправлением дневного расписания. Из отправлений с подтверждённым `ramp = 1` формировать **второе, низкопольное расписание**. |
| Построение пути | Транспортные участки и пересадки ищет `LiveTransit` по машинам на линии. OpenTripPlanner (OTP) строит пешие участки. Если автобус уже проехал остановку посадки, расчёт может пропустить следующий рейс. | OTP строит весь путь по выбранному расписанию и пешеходной сети OSM. Свежий прогноз влияет на выбор посадки и пересадки. Сравниваем полное время от А до Б с учётом ходьбы, ожидания и поездки. |
| Выбор режима | Один переключатель «Низкопольный транспорт», по умолчанию выключен (любой транспорт с пометкой); ключ хранения `gopoint.lowFloorOnly.v2`. | По умолчанию — **«Низкопольный транспорт»** (решение владельца 21.11.2026, заменяет решение шага 02). Рейсы без подтверждённой низкопольной машины в этом режиме не показываются. Каждую посадку, включая пересадки, подбирать по низкопольному расписанию. При выборе **«Весь транспорт»** использовать общее дневное расписание. |
| Варианты поездки | На прямом направлении приложение иногда отвечает «Транспорта сейчас нет». | Если машина ушла в депо или пропал GPS, сохранять схему пути и длительность проезда. Для ожидания брать следующее подходящее отправление. Если ожидание неизвестно, указывать это отдельно (в низкопольном режиме неподтверждённый рейс не показывается). При наличии двух подходящих вариантов показывать оба, пешие участки включать в шаги поездки. |
| Карта и панорамы | Стандартная подложка OSM уже подключена. Машины между опросами плавно движутся 1,5 с и затем стоят до следующего снимка (≈ 30 с), а панорама может открыться в стороне от остановки. | Сохранить подложку, плавно перемещать маркеры между GPS-отметками. По нажатию на панораму показывать нужную посадочную площадку. |
| Поиск точек А и Б | Точный адрес бывает трудно найти. Свой список названий (`aliases_nsk.csv`: НГУ, вокзал, больница 1, автовокзал) и остановки ЦУГАЭТ уже подмешиваются в выдачу. По названию места в выдачу может попасть одноимённая трасса. | По запросу «Военная 5» находить здание с этим адресом, по «Кольцово» — населённый пункт. Давать выбрать улицу без номера или точку на карте и сохранять названия А и Б в маршруте. Поиск отложен до проверки ядра маршрутизации. |

**Контрольный пример — «Цветной проезд → Речной вокзал».** На автобусе № 8 предстоит проверить покрытие официального расписания, различить два соседних отправления по данным ЦУГАЭТ и показать прямую поездку после ухода предыдущей машины. Отдельная проверка для OTP — подобрать низкопольный транспорт на обеих посадках в поездке с пересадкой.
