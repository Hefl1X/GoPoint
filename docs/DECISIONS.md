У каждого решения есть строка «когда пересмотреть».

**Слабые места простыми словами:**
- Поиск ищет слова из названия на карте, а не смысл. «Вокзал» находит другой вокзал (Новосибирск-Западный)
  и улицу «Вокзальная магистраль»; нужно писать «Новосибирск-Главный» или «вокзал главный».
- Сокращения работают, только если они записаны на карте: «НГТУ», «СГУПС», «НГМУ» находятся, «НГУ» нет (находит НГУЭиУ).
  У своего сервера есть файл синонимов (`-synonym-file`), им это можно поправить позже.
- Номера в названиях больниц путаются: на «больница 1» первой выходит «больница № 2», нужная второй.
- Похожие места стоят рядом в списке (два краеведческих музея, магазин в нужном доме): человеку нужно смотреть
  на адрес под названием. Поэтому адрес показывается второй строкой.
- Адреса такие, какими они были на карте 31 октября 2026: новые дома появятся после пересборки базы.
- Если места нет в подсказках, всегда можно «Выбрать на карте».
