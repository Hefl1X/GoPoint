# Решения по проекту GoPoint

Технические решения принимает Claude Code, решения о поведении для пользователя принимает владелец.
У каждого решения есть строка «когда пересмотреть».

| Дата | Решение | Почему | Когда пересмотреть |
|---|---|---|---|
| 2026-11-04 | Python ставится через `uv` (версия 3.12 закреплена в `server/pyproject.toml`), зависимости закреплены в `server/uv.lock` | `uv` уже был на Mac, сам скачивает нужный Python, один инструмент вместо pip + venv + pyenv | если `uv` перестанет поддерживаться или CI не сможет его поставить |
| 2026-11-04 | React 19, а не 18, как написано в ARCHITECTURE.md | на ноябрь 2026 это текущая стабильная версия; 18 уже старая, новые библиотеки рассчитаны на 19 | при выходе React 20 |
| 2026-11-04 | TypeScript 5.9, ESLint 9 (а не новейшие 7 и 10) | `openapi-typescript` (генерация типов API) работает только с TypeScript 5, `eslint-plugin-jsx-a11y` (проверка доступности) только с ESLint до 9 | когда эти два пакета поддержат новые версии |
| 2026-11-04 | `npm audit` сообщает об уязвимости средней тяжести в `minimatch` внутри ESLint и `openapi-typescript` | это инструменты проверки кода, в собранный сайт они не попадают; исправление требует откатить плагин доступности на старую версию | при обновлении ESLint и плагинов; если уязвимость появится в пакетах, которые попадают в сайт |
| 2026-11-04 | Сайт собирается в статику внутри образа Caddy: в `docker-compose.yml` два сервиса, `server` и `caddy` (вместо трёх `web`, `server`, `caddy`) | отдельный контейнер `web` только копировал бы файлы; так проще и нет риска раздать устаревшую сборку | если сайту понадобится свой сервер (например, отрисовка на сервере) |
| 2026-11-04 | Сайт всегда обращается к API по своему же адресу (`/api/v1`), Caddy передаёт запросы серверу | адрес сервера не зашит в клиент: одинаково работает на Mac, на телефоне по Wi-Fi и на VPS; CORS не нужен | если API переедет на отдельный домен |
| 2026-11-04 | Наружу открыт только Caddy (порты 8080 и 8443 на Mac); сервер в внутренней сети Docker | требование безопасности из CLAUDE.md | при переносе на VPS проверить ещё раз |
| 2026-11-04 | Caddy и сервер не пишут журнал запросов (`log discard`, `--no-access-log`) | в адресах запросов будут координаты пользователей, а их нельзя писать в логи | когда понадобится мониторинг: писать только код ответа и время, без адресов |
| 2026-11-04 | Описание API открывается по `/api/docs`, контракт по `/api/openapi.json` (а не `/docs`) | через Caddy наружу идёт только `/api/*`, так описание доступно и с телефона | если описание нужно спрятать при публикации (решить перед этапом 2) |
| 2026-11-04 | Все адреса API из раздела 9 уже описаны в контракте; пока не сделанные отвечают кодом 501 и сообщением «Эта функция ещё в разработке.» | сайт может строиться на сгенерированных типах заранее; ответ честно говорит, что функции нет | по мере выполнения запросов 2–8 |
| 2026-11-04 | Служебные поля (способ расчёта прихода, время отметки машины) собраны в объект `diagnostics` и поле `positionObservedAt` | их легко не показывать в интерфейсе и удобно проверять в тестах | если появятся новые служебные поля |
| 2026-11-04 | Границы Новосибирска пока прямоугольник 54.80–55.20 с. ш., 82.70–83.20 в. д. (настройка `GOPOINT_CITY_*`) | нужен для `/meta` уже сейчас; точная граница появится с выгрузкой OpenStreetMap (запрос 5) | в запросе 5: заменить на границу города из OSM |
| 2026-11-04 | `STALE_SECONDS` = 300 по умолчанию | значение из CLAUDE.md; владелец его подтверждает | после проверки живых данных (запрос 2, `DATA_QUALITY.md`) |
| 2026-11-04 | Ошибки проверки ввода (422) не повторяют присланные значения | в них могут быть координаты пользователя | не пересматривается |
| 2026-11-04 | Работа ведётся в ветках `тип/задача`, после проверок ветка вливается в `main` | правило CLAUDE.md «одна ветка на задачу»; владельцу удобнее, что `main` всегда рабочая | когда появится GitHub и pull request'ы |
| 2026-11-04 | Код хранится в закрытом репозитории GitHub `Hefl1X/GoPoint`, CI на GitHub Actions | решение владельца: закрытый, пока нет письменного разрешения ЦУГАЭТ (в репозитории их образцы данных) | при получении разрешения ЦУГАЭТ или если кончатся бесплатные минуты Actions |
| 2026-11-04 | Маршрутки (minibus) включены: `GOPOINT_TRANSPORT_TYPES=bus,trolleybus,tram,minibus`, 104 маршрута, 18 запросов за опрос | **решение владельца** 4 ноября. При включённой настройке «Низкопольный транспорт» маршрутки почти не видны (по замеру 3 низкопольные из 134), при выключенной видны все с пометкой | если ЦУГАЭТ скажет, что признак `ramp` у маршруток не заполняется |
| 2026-11-04 | id маршрута `вид-код` (`bus-3`, `tram-0013`), id машины `вид-код-выход` (`bus-3-1`) | номера повторяются у разных видов (автобус 13 и трамвай 13); выход (graph) единственный устойчивый номер машины в данных | если ЦУГАЭТ даст бортовые номера |
| 2026-11-04 | Опрос машин: один на всех, раз в 30 с, пачки по 6 маршрутов, пауза 0,5 с, только если к API обращались за последние 2 мин | правила CLAUDE.md; так нагрузка на ЦУГАЭТ не зависит от числа пользователей | при письменном разрешении ЦУГАЭТ с другой частотой |
| 2026-11-04 | Если сервер давно никто не спрашивал (снимок старше 60 с), первый запрос ждёт новый опрос (около 7 с), а не отдаёт старые положения | человеку на коляске нельзя показывать машину там, где её уже нет | если ожидание окажется неудобным: показывать загрузку на сайте (запрос 3) |
| 2026-11-04 | При сбое ЦУГАЭТ отдаётся прошлый снимок, но устаревшие (старше 5 мин) машины всё равно скрываются; если не пришла часть пачек, для этих маршрутов берутся машины из прошлого снимка | правило «устаревшее положение не показывается» важнее полноты | не пересматривается |
| 2026-11-04 | Отметка машины «из будущего» больше чем на 2 мин считается ошибкой, машина не показывается | защита от сбитых часов у машины или у нас | после наблюдений в DATA_QUALITY.md |
| 2026-11-04 | Линии и остановки (`trasses.php`) не опрашиваются заранее, а берутся при первом открытии маршрута и хранятся сутки | меньше запросов к ЦУГАЭТ: 2 запроса на маршрут в сутки, только для открытых | если экран маршрута будет открываться медленно |
| 2026-11-04 | Прогноз на остановке ЦУГАЭТ (`forecast.php`) не переносится в сервер | в нём нет номера выхода, по нему нельзя узнать, низкопольная ли машина (NSKGORTRANS.md) | если ЦУГАЭТ добавит выход в прогноз |
| 2026-11-04 | User-Agent запросов к ЦУГАЭТ: `GoPoint/<версия> (non-commercial accessible transit demo, Novosibirsk)`, без контактов | требование «идентифицируемый, без личных данных»; почту владельца без его согласия не публикуем | если ЦУГАЭТ попросит контакт в заголовке |
| 2026-11-04 | `pytest-asyncio` (Apache-2.0) для тестов асинхронного кода | стандартный способ тестировать asyncio в pytest | не пересматривается |
