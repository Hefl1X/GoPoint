## Известные ошибки и ограничения
- Страница `/api/docs` (Swagger) подгружает оформление с cdn.jsdelivr.net: без интернета не откроется.
  Для демо неважно.
- Предупреждение в тестах сервера: Starlette советует `httpx2` для тестового клиента. На работу не влияет;
  пересмотреть при обновлении FastAPI.
- Проверка «контракт API актуален» в `check-all.sh` сравнивает с последним коммитом: локально только
  предупреждает, в CI падает.
- Границы города пока прямоугольник (см. DECISIONS.md).
- Первый запрос к `/live/*` после 2 минут тишины ждёт опрос ЦУГАЭТ около 8 с (на сайте видно «Загружаем…»).
- Пока туннель работает, сайт доступен из интернета по случайному адресу; трафик идёт через localhost.run.
  Бесплатный туннель иногда обрывается: тогда `run-tunnel.sh` ещё раз.
- Карта при первом открытии на телефоне грузится до 20 с (тайлы OpenFreeMap), в это время фон пустой.
- Карта на телефоне по Wi-Fi грузится несколько секунд: тайлы идут с OpenFreeMap.
- Сборка сайта предупреждает, что файл карты больше 500 КБ: это MapLibre, он грузится отдельно.
- Проверка на настоящем телефоне владельцем ещё не проводилась.
- `/live/vehicles/{id}`, `/live/stops/{id}/arrivals`, `/route` пока отвечают 501 (запрос 6).
- Без собранной базы (`build-photon-db.sh`) поиск адресов на сайте отвечает «Поиск адресов сейчас не работает».
- Адреса в базе на 31.10.2026; обновление: `bash scripts/build-photon-db.sh --fresh`.
- Уклоны не учитываются (рельеф выключен), пешее время считается как по ровному месту.
- OTP обходит лестницы и высокие бордюры штрафом, а не запретом: если иначе никак, путь пойдёт через лестницу
  (в ответе `hasStairs: true`, в проверке так вышел маршрут 9 «Площадь Маркса → Мега»).
- Слабые места поиска (вокзал, «метро …», «НГУ», номера больниц) описаны в `DECISIONS.md`.
- Точки А и Б после перезагрузки страницы пропадают (так задумано: адреса не хранятся на устройстве).
- Значки А и Б на карте видны экранной читалке только как подписи значков; управлять ими с клавиатуры нельзя
  (точку можно выбрать поиском).
- У 8 маршрутов (трамваи 2 и 8, шесть маршруток) обратное направление пустое: в `/live/routes/{id}`
  приходит одно направление.
- Работа «прошлого снимка» при отключённом интернете проверена автоматическими тестами,
  вручную с выключенным интернетом не проверялась.

## Как запустить и проверить
- Демо: `bash scripts/run-demo.sh` → `http://localhost:8080`, описание API `http://localhost:8080/api/docs`,
  на телефоне адрес из вывода скрипта.
- Проверки: `bash scripts/check-all.sh` (без e2e: `--fast`).
- Граф улиц для пеших участков (один раз и для обновления): `bash scripts/build-otp-graph.sh` (`--fresh`, `--with-dem`).
- Проверка 10 пеших маршрутов: как `geocoder_quality`, но `python -m tools.walk_check <папка>` (см. начало файла
  `server/tools/walk_check.py`); карту `walk_check.html` открывать через веб-сервер (`python3 -m http.server`).
- База поиска адресов (один раз и для обновления): `bash scripts/build-photon-db.sh` (`--fresh` скачает новую выгрузку).
- Качество поиска адресов на своём Photon (сеть, вручную, не чаще раза в день):
  `C=$(docker compose ps -q server); docker cp server/tools $C:/tmp/tools; docker cp data/geocoder/places_nsk.csv $C:/tmp/`,
  затем `docker compose exec -w /tmp server sh -c 'PYTHONPATH=/app:/tmp /app/.venv/bin/python -m tools.geocoder_quality /tmp/places_nsk.csv'`.
- Только сервер для разработки: `cd server && uv run uvicorn app.main:app --reload`;
  только сайт: `cd web && npm run dev` (запросы `/api` уходят на 127.0.0.1:8000, или на
  `GOPOINT_API_PROXY`, например `http://127.0.0.1:8080`, если запущено демо в Docker).
- Список машин вместо карты: добавить `?map=list` к адресу.
- Временный HTTPS-адрес для телефона: `bash scripts/run-tunnel.sh`, выключить `bash scripts/stop-tunnel.sh`.
- Изменился API на сервере → `uv run python -m app.openapi_export ../web/src/adapters/api/openapi.json`
  в `server/`, затем `npm run api:types` в `web/` (или просто `check-all.sh`).
