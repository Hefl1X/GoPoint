# Качество данных ЦУГАЭТ

Что известно о данных сайта map.nskgortrans.ru по измерениям, а не по догадкам.
Описание полей: `data/tsugaet/NSKGORTRANS.md`.

Первый отчёт появится в запросе 2 (адаптер ЦУГАЭТ):
- сколько маршрутов и машин на линии;
- доля машин с `ramp` = 1, 0 и без признака;
- как часто обновляются отметки положения;
- есть ли у каждой остановки координаты;
- насколько `segment_order` согласован с положением машины на линии (проверка на 10 машинах).

## Вопросы к ЦУГАЭТ

См. раздел «Открытые вопросы» в `data/tsugaet/NSKGORTRANS.md`. Дополняется по ходу проверки.
