# Как запустить демо GoPoint на Mac

Простая инструкция для показа. Подробности и все команды: `README.md`.

## Перед показом (один раз, заранее, нужен интернет)

1. **Docker Desktop.** Установите с docker.com, откройте (значок кита в «Программах») и дождитесь,
   пока он напишет, что работает.
2. **Память для Docker.** Docker Desktop → Settings → Resources → Memory: нужно **не меньше 4 ГБ**
   (OpenTripPlanner, который считает путь пешком, занимает около 600 МБ, при сборке до 3 ГБ;
   поиск адресов ещё около 450 МБ). Сейчас на Mac 7,7 ГБ: хватает, менять ничего не нужно.
3. **Граф улиц для пеших участков** (около 5 минут, скачивается 590 МБ):
   ```bash
   bash scripts/build-otp-graph.sh
   ```
4. **База поиска адресов** (около 5 минут, скачивается 1,5 ГБ):
   ```bash
   bash scripts/build-photon-db.sh
   ```
5. Проверьте, что всё на месте: `bash scripts/check-mac.sh` должен написать «всё готово».

Без шагов 3 и 4 демо тоже запускается, но скрипт предупредит: без графа улиц маршрут не строится
(сайт говорит «Не удалось посчитать путь по улицам»), без базы адресов не работают подсказки
(точки можно выбрать на карте).

## Запуск (одна команда)

Откройте «Терминал», перейдите в папку проекта и выполните:

```bash
bash scripts/run-demo.sh
```

Первый раз сборка идёт несколько минут, потом около 30 секунд. Скрипт напечатает:
- адрес для этого компьютера: `http://localhost:8080`;
- адрес для телефона: `http://192.168.…:8080` (телефон в той же сети Wi-Fi, не гостевой).

Остановить: `bash scripts/stop-demo.sh`.

## Чтобы Mac не заснул

В отдельном окне «Терминала» выполните и не закрывайте окно до конца показа:

```bash
caffeinate -dims
```

Ноутбук подключите к зарядке, крышку не закрывайте. Закончить: Control+C.

## Открыть на телефоне

- **Просто посмотреть:** адрес `http://192.168.…:8080` из вывода скрипта. Работает всё, кроме
  кнопки «Моё местоположение» и установки на экран телефона: браузер даёт их только защищённым
  адресам (https).
- **С местоположением и установкой на экран:** после запуска демо выполните
  ```bash
  bash scripts/run-tunnel.sh
  ```
  и откройте на телефоне адрес `https://….lhr.life` из вывода. **Пока туннель работает, сайт
  открыт всему интернету** (по случайному адресу). После показа: `bash scripts/stop-tunnel.sh`.

## За 10 минут до показа

1. `bash scripts/run-demo.sh` → откройте `http://localhost:8080`, на карте видны машины.
2. Постройте один маршрут из сценария (`docs/DEMO_CHECKLIST.md`, раздел 8): первый расчёт после
   запуска идёт до 25 секунд (сервер загружает линии всех маршрутов), дальше быстро.
3. Откройте сайт на телефоне, проверьте, что карта и машины видны.

## Если не запустилось

| Что видно | Что делать |
|---|---|
| «Docker не запущен» | Откройте Docker Desktop, подождите минуту, запустите команду снова |
| «Docker не установлен» | Установите Docker Desktop с docker.com |
| «Сервис не ответил за 2 минуты» | Выполните `docker compose logs --tail 50` и пришлите результат. Частая причина: мало памяти у Docker (см. выше) |
| Сайт открылся, но «Транспорта сейчас нет» везде | Ночью (примерно с 23:00 до 6:00) машин на линии мало или нет. Проверьте «Транспорт» внизу: если везде «сейчас нет на линии», так и есть |
| «Не удалось получить данные о транспорте» | Нет интернета на Mac или сайт ЦУГАЭТ не отвечает. Проверьте интернет; сервер сам повторит через 30 секунд |
| «Не удалось посчитать путь по улицам» | Не собран граф улиц: `bash scripts/build-otp-graph.sh`, затем снова `run-demo.sh` |
| «Поиск адресов сейчас не работает» | Не собрана база адресов: `bash scripts/build-photon-db.sh`. Пока можно выбирать точки на карте |
| Карта серая, машины списком, надпись «Карта сейчас не загружается» | Не отвечает сервер карты (OpenFreeMap) или нет интернета. Транспорт и маршрут при этом работают |
| Телефон не открывает адрес | Телефон и Mac в одной сети Wi-Fi (не гостевой)? При первом запуске macOS спрашивает про входящие подключения для Docker: «Разрешить» |
| Туннель перестал открываться | Бесплатный туннель иногда обрывается: `bash scripts/run-tunnel.sh` ещё раз (адрес будет новый) |

Проверено 05.11.2026: демо запускается из чистой папки (новая копия репозитория), см.
`docs/DEMO_CHECKLIST.md`, раздел 7.
