# Плановое расписание ЦУГАЭТ (grasp.php)

Разбор от 21.11.2026 по разовым образцам в `samples/schedule/` (автобус № 8, трамвай 13, маршрутка № 35), сделанным с согласия владельца. Регулярная загрузка не включена: её отдельно согласует владелец.

Страница для людей: https://www.nskgortrans.ru/site/rasp. Её скрипт (`/themes/goodnex/js/raps.min.js`) ходит в
`https://nskgortrans.ru/components/com_planrasp/helpers/grasp.php`. Ключей и авторизации нет.

## Цепочка запросов

| Шаг | Запрос | Ответ | Образец |
|---|---|---|---|
| 1. Номер | `?q=8` | строки `номер\|номер\|тип\|код`; тип 1 автобус, 2 троллейбус, 3 трамвай, 8 маршрутка; код = `marsh` из `listmarsh`/`markers` (`8`, `0013`, `35`) | `q8.txt`, `q35.txt` |
| 2. Направления | `?m=<код>&t=<тип>` | XML `<route id='A\|B' title='Откуда - Куда'/>` | `dir8.xml`, `dir13.xml`, `dir35.xml` |
| 3. Типы дня | `…&r=A` | XML `<schedule id='23' title='ЕЖЕДНЕВНО'/>`; у трамвая 13 — `БУДНИ` (11) и `ВЫХОДНОЕ` (5) | `sch8A.xml`, `sch13A.xml`, `sch35A.xml` |
| 4. Остановки | `…&r=A&sch=<id>` | XML `<stop id='<id остановки>\|<порядок>' title='Название'/>` — **все** остановки направления по порядку | `stops8A.xml`, `stops13A.xml`, `stops35A.xml` |
| 5. Расписание остановки | `?tv=mr&m=…&t=…&r=…&sch=…&s=<id\|порядок>&v=0` | HTML-таблица `td_plan_h` (час) + `td_plan_m` (минуты в `<div>`); `td_plan_n` — час без отправлений | `tt8A_s1.html` и др. |
| 5б. Интервалы | то же с `v=1` | начало и конец движения, «прогнозируемый интервал» по периодам дня (у № 8: 6–9, 9–15, 15–19, 19–24) | `tt8A_s1_int.html` |

В шапке расписания дата («Дата: 20.11.2026») и оговорка: «Транспортные средства, выходящие из депо или движущиеся в депо, проходят вне расписания».

## Что есть и чего нет

- **Есть:** все остановки по порядку, отправления по каждой остановке на тип дня, первый и последний рейс.
- **Нет:** номера выхода (`graph`), признака низкого пола, номера рейса. Связать рейс с машиной можно только по времени и положению (см. ниже).
- **Время в пути постоянно весь день.** Смещение от конечной одинаково для всех рейсов: № 8 A — +2 мин до 2-й остановки и +69 мин до «М. Речной вокзал» у всех 55 рейсов; № 35 A — +78 мин до конечной у всех 97 рейсов. Значит, таблицы остановок — это отправления с конечной плюс постоянный шаблон времени хода. Пробки расписание не учитывает: задержку даёт только GPS.
- **Число отправлений одинаково на всех проверенных остановках** направления (55 у № 8, 97 у № 35): рейс восстанавливается по порядковому номеру отправления. Укороченные рейсы и заезды в депо на образцах не встречены — проверить на других маршрутах.
- **Id остановок не совпадают с `trasses`** (трамвай 13 A: общих id нет), но **названия совпадают 25 из 25 в том же порядке** (`normalize_stop_name`); в `trasses` конечная повторяется в конце. Привязка — по названию и порядку.
- Автобус № 8 A проходит «М. "Речной вокзал"» (31-я остановка из 38): контрольная поездка шага 04 возможна и на № 8, и на маршрутке № 35.

## Объём загрузки

- Таблица каждой остановки: ≈ 104 маршрута × 2 направления × 1–2 типа дня × ~30 остановок ≈ 9 000 запросов — слишком много для регулярного обновления.
- Достаточно таблицы конечной на направление и тип дня (≈ 300 запросов, при паузе 1,5 с ≈ 8 минут) плюс шаблона времени хода. Шаблон: разово по всем остановкам или по нескольким опорным с интерполяцией по расстоянию вдоль линии. Выбор — с владельцем.
